# FocusCoin

공부 시간을 코인으로 적립하고, 사용자가 직접 고른 앱의 이용 시간을 코인으로 관리하는 Android 집중 습관 앱입니다. 모든 앱 데이터는 기기에 저장하며 로그인, 서버 동기화, 광고, 결제 기능은 포함하지 않습니다.

## APK 다운로드

[최신 FocusCoin APK 다운로드](https://github.com/bocado-app/focuscoin1/releases/latest/download/FocusCoin.apk)

휴대폰에서 링크를 열어 APK를 내려받고 설치하세요. Android에서 설치를 차단하면 설정에서 브라우저의 '알 수 없는 앱 설치'를 허용해야 할 수 있습니다. 설치 후에는 이 권한을 다시 끌 수 있습니다.

## 기술 구성

- Kotlin, Jetpack Compose, Material 3
- MVVM + Navigation Compose
- DataStore: 코인·휴식 시간 잔액, 설정, 타이머 복원 정보
- Room: 공부 세션, 날짜별 학습 메모, 과목별 시험 계획, 5등급 성적 기록, 대학별 참고 기준, 코인 거래, 앱 잠금 설정, 공부 앱 보너스 기록, 요일별 플래너 일정
- 최소 SDK 26 (Android 8.0)
- Android Gradle Plugin 8.7.3, Gradle 8.9, JDK 17

## 실행

1. Android Studio에서 이 저장소의 `FocusCoin` 폴더를 엽니다.
2. JDK 17과 Android SDK 35를 설치합니다.
3. Gradle 동기화가 끝나면 에뮬레이터 또는 기기를 선택해 `app` 구성을 실행합니다.

명령줄에서는 프로젝트 폴더에서 실행합니다.

```bash
sh ./gradlew assembleDebug
```

Windows에서는 다음 명령을 사용합니다.

```powershell
.\gradlew.bat assembleDebug
```

첫 실행 시 Gradle 8.9 배포 파일을 다운로드합니다. 실행 환경에는 JDK 17이 필요합니다. APK는 `app/build/outputs/apk/debug/app-debug.apk`에 생성됩니다.

## GitHub 빌드

`.github/workflows/android.yml`은 `main`/`master` 브랜치 push와 pull request마다 디버그 APK를 빌드합니다. 성공한 실행의 `FocusCoin-debug` 아티팩트를 Actions 페이지에서 받을 수 있습니다. 친구들에게 배포할 때는 아래 Release APK 링크를 사용하면 됩니다.

`v1.0.0` 형식의 태그를 push하면 `.github/workflows/release.yml`이 APK를 빌드해 GitHub Release에 `FocusCoin.apk` 이름으로 첨부합니다. 서명 키 비밀을 등록하지 않아도 설치 테스트용 APK를 받을 수 있습니다. 이 APK는 Actions 실행 환경에서 만들어진 debug 키로 서명되므로, 추후 업데이트를 같은 앱으로 설치할 때 서명이 달라질 수 있습니다. 키가 다르면 이전 앱을 제거한 뒤 설치해야 하고, 앱을 제거하면 기기에 저장된 데이터가 삭제됩니다.

지속적인 앱 업데이트를 배포하려면 저장소 설정의 **Settings → Secrets and variables → Actions**에 동일한 release keystore로 다음 저장소 비밀을 등록하세요. keystore 파일과 비밀번호는 저장소에 커밋하지 않습니다.

- `ANDROID_KEYSTORE_BASE64`: release keystore 파일의 Base64 문자열
- `ANDROID_KEYSTORE_PASSWORD`: keystore 비밀번호
- `ANDROID_KEY_ALIAS`: 서명 키 별칭
- `ANDROID_KEY_PASSWORD`: 서명 키 비밀번호

태그 버전은 APK 버전명과 버전 코드에 반영됩니다. Release APK는 아래 고정 주소에서 받을 수 있습니다.

```text
https://github.com/bocado-app/focuscoin1/releases/latest/download/FocusCoin.apk
```

저장소를 GitHub에 올릴 때는 GitHub에서 빈 저장소를 만든 뒤 아래 예시처럼 연결합니다.

```bash
git init
git add .
git commit -m "Build FocusCoin MVP"
git branch -M main
git remote add origin https://github.com/bocado-app/focuscoin1.git
git push -u origin main
```

## MVP 동작

- 첫 실행 목적 및 알림·사용 기록·접근성 권한의 선택적 안내
- 25분, 50분, 90분 및 직접 입력 집중 타이머
- 분 단위 코인 정산, 완주 보너스, 중도 종료 확인
- 타이머 상태를 DataStore에 저장해 앱 재실행 후 복원
- 실행 가능한 앱 목록과 선택 앱의 잠금·이용권 가격 설정
- 앱별 공부 보너스 선택: 공부 모드가 진행 중일 때 선택 앱의 실제 화면 사용 1분마다 보너스 1코인 적립, 기본 하루 상한 60코인(설정에서 변경 가능)
- 스터디 플래너: 반복 요일, 시간, 허용 앱을 지정하고 일정 중 허용 목록 밖의 일반 앱을 제한
- 시험·과목 플래너: 과목별 시험 날짜와 하루 목표를 등록하고 오늘 목표 진행 상황과 D-day를 확인
- 대학 추천 참고: 학기·과목별 5등급과 이수 단위를 기록하고, 사용자가 출처와 함께 입력한 대학별 기준 등급을 도전·근접·여유로 분류해 목표 준비도를 표시
- 대학별 참고 데이터는 사용자가 관리합니다. 합격 가능성을 예측하거나 보장하지 않으며, 5등급제 실적이 축적되기 전에는 예시 합격선을 임의로 만들지 않습니다.
- 홈의 오늘 할 일: 다가오는 시험이 가까운 순으로 과목별 오늘 공부 목표와 남은 시간을 보여주고, 과목 타이머를 바로 시작
- 과목별 타이머 연결: 세션을 과목에 기록해 시험 계획의 실제 공부 시간에 반영
- 계획된 휴식: 누적 공부 25분마다 휴식 5분 적립, 휴식 중 앱 제한을 잠시 풀고 조기 종료 시 남은 온전한 분은 환급
- 오늘의 학습 한 줄: 홈에서 200자까지 기록하고 리포트에서 오늘·이번 주 메모를 날짜별로 확인
- 보너스 적립은 사용 기록 접근을 허용하고 공부 앱을 직접 선택한 경우에만 동작하며, 권한이 없어도 타이머와 기본 코인 적립은 계속 사용 가능
- 접근성 서비스는 `TYPE_WINDOW_STATE_CHANGED` 이벤트의 패키지명만 검사하며 노드 트리나 화면 내용을 가져오지 않음
- 잠금 안내, 코인 구매, 하루 1회 긴급 해제
- 오늘·주간 리포트, 주간 공부 막대 그래프, 규칙 기반 피드백
- 설정, 개인정보 안내, 로컬 데이터 초기화, 다크 모드

## 개인정보 범위

Room에는 사용자가 직접 고른 잠금 앱과 공부 보너스 앱의 패키지명·앱 이름·설정, 플래너 일정과 허용 앱, 과목별 시험 날짜·목표, 학기별 5등급 성적, 대학별 참고 기준과 출처, 과목에 연결된 공부 세션, 날짜별 학습 메모, 코인 거래 내역, 보너스 정산에 필요한 선택 앱의 사용 시간 누적값을 저장합니다. DataStore에는 코인 및 휴식 시간 잔액, 설정, 타이머와 진행 중 휴식 복원 상태를 저장합니다. 사용 기록 접근은 선택한 패키지만 조회하고, 사용 시간과 거래 내역은 기기에만 보관합니다. 플래너 일정이 켜져 있으면 접근성 서비스가 실행 앱의 패키지명을 확인해 허용 목록을 적용합니다. 계획된 휴식 중에는 시간이 끝날 때까지 앱 제한을 잠시 해제합니다. 화면 텍스트, 입력, 메시지, 비밀번호, 연락처, 캡처를 읽거나 저장하지 않습니다. 서버 전송이나 계정 동기화는 없습니다.

## 수동 확인 방법

에뮬레이터 또는 Android 8.0 이상 기기에서 다음 순서로 확인합니다.

1. 앱을 설치하고 온보딩을 완료합니다. 권한을 거부한 상태에서도 홈과 타이머가 열리는지 확인합니다.
2. 1~2분 직접 타이머를 실행한 뒤 일시정지·재개하고, 앱을 닫았다 다시 열어 남은 시간이 이어지는지 확인합니다.
3. 1분 이상 공부를 종료하고 코인 잔액·거래 내역·오늘 리포트가 갱신되는지 확인합니다. 짧은 타이머를 완주해 보너스 적립도 확인합니다.
4. 사용 기록 접근을 허용한 뒤 잠금 앱 화면에서 공부 앱 보너스를 켭니다. 타이머 진행 중 그 앱을 1분 이상 열고, 보너스 잔액과 리포트의 앱별 적립 내역을 확인합니다. 타이머 밖에서 사용한 시간은 적립되지 않는지 확인합니다.
5. 스터디 플래너에 반복 요일과 시작·종료 시각을 정하고 일정 중 허용할 앱을 선택합니다. 접근성 설정에서 FocusCoin 서비스를 켠 뒤 허용 목록 밖의 앱이 안내 화면으로 제한되는지 확인합니다.
6. 잠금 앱 화면에서 테스트 앱을 선택하고 해제 시간·비용을 바꿉니다. 접근성 설정에서 FocusCoin 서비스를 켠 뒤 선택 앱을 열어 잠금 안내가 나타나는지 확인합니다.
7. 코인이 충분할 때 이용권을 확인 구매하고 앱이 설정한 시간 동안 열리는지 확인합니다. 코인이 부족한 상태와 긴급 해제 1회 제한도 확인합니다.
8. 리포트의 오늘/이번 주 전환, 주간 막대, 앱 구매 합계와 설정의 코인 비율·완주 보너스·데이터 초기화를 확인합니다.
9. 시험·과목 플래너에 과목과 시험 날짜, 하루 목표를 등록한 뒤 과목을 선택해 타이머를 시작합니다. 종료 후 오늘 목표 진행과 과목명이 기록되는지 확인합니다.
10. 완료한 공부 시간을 누적해 25분을 채우면 휴식 5분이 적립되는지 확인합니다. 휴식을 시작하면 앱 제한이 해제되고, 일찍 끝내면 남은 온전한 분이 지갑으로 돌아오는지 확인합니다.
11. 홈의 오늘의 학습 한 줄을 저장하고, 리포트의 오늘·이번 주 화면에서 해당 메모가 표시되는지 확인합니다. 앱을 재시작한 뒤에도 저장 내용이 유지되는지 확인합니다.
12. 시험·과목 플래너에 과목별 시험 날짜와 하루 목표를 등록합니다. 홈에서 가까운 시험 과목이 먼저 표시되고, 오늘 공부한 시간에 따라 남은 목표가 줄어드는지와 과목별 공부하기 버튼이 해당 과목 타이머를 여는지 확인합니다.
13. 플래너의 대학 추천에서 학기별 과목 등급과 이수 단위를 입력하고, 공개 자료를 참고해 대학·학과·전형별 기준 등급과 출처를 추가합니다. 가중 평균, 도전·기준 근접·기준 여유 분류, 목표 준비도와 주간 약점 과목 미션이 갱신되는지 확인합니다. 표시된 분류가 합격 확률이 아님을 확인합니다.

Android와 제조사별 접근성/사용 기록 설정 화면은 표시 방식이 다를 수 있습니다. 접근성 허용을 거부해도 타이머, 코인, 리포트 기능은 사용할 수 있습니다.
